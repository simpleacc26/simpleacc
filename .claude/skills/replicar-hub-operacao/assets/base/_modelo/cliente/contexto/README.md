# Contexto — <Nome do Cliente>

Base do cliente: quem é, oferta, ICP, análise de mercado e linguagem (frases reais
do público). É daqui que os prompts mestres e as skills puxam o contexto.
Mantenha atualizado — é o insumo que separa entrega genérica de entrega sob medida.

Sugestão de arquivos:

- `quem-e.md` — história, credenciais, provas, jeito de falar
- `oferta.md` — o que vende, preço, formato de entrega, garantias
- `icp.md` — para quem vende, dores, objeções, gatilhos de decisão
- `mercado.md` — concorrentes, ângulos já usados no nicho, referências
- `linguagem.md` — frases literais do público (comentários, DMs, calls)
