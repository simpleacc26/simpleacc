# Contexto — <Nome do Cliente>

Base do cliente: quem é, oferta, ICP, análise de mercado e linguagem (frases reais do público). É daqui que o comando `/prompt-mestre` puxa o contexto. Mantenha atualizado.

O arquivo `contexto-estrategico.md` é o **contexto estratégico permanente** que o comando
`/conselho-estrategico` lê antes de qualquer conselheiro falar (empresa, time, mercado,
operação, finanças). Preencha o que souber e atualize sempre que um número mudar.
