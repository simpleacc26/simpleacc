**Replicar o hub da operação** — a skill que monta esta mesma estrutura
compartilhada numa operação nova: esqueleto do repositório com placeholders,
documentação de contas (GitHub, Claude Code, Vercel, Workspace, conectores) e
scripts de geração. É também um **pacote portátil**: o zip em
[`pacotes/replicar-hub-operacao.zip`](pacotes/replicar-hub-operacao.zip) sobe
direto em outra conta Claude (Configurações → Capacidades/Skills → Enviar
skill). Comece por
[`README-INSTALACAO.md`](../../.claude/skills/replicar-hub-operacao/README-INSTALACAO.md)
ou peça numa sessão: *"monta a estrutura do hub da operação nova"*.
