## Como usar no treino

1. Leia primeiro a [análise](../analise-call-daniel-kaina-2026-07-30.md) — o mapa em
   blocos com timestamps.
2. Depois assista/leia a call inteira acompanhando o mapa, marcando onde cada
   mecanismo aparece.
3. Feche com o [playbook](../playbook-call-carlos-ticket-2497.md) e o
   [cheat sheet](../cheatsheet-call-1-pagina.md).

## Ao adicionar uma call nova

- Nome do arquivo: `AAAA-MM-DD-<vendedor>-x-<lead>.md`
- Registre na tabela acima com o resultado (fechou / não fechou / valor)
- Se a call gerou aprendizado novo de script ou objeção, atualize o playbook junto
