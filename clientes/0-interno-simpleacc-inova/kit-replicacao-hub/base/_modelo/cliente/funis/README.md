# Funis — <Nome do Cliente>

Funis, landing pages e quizzes. Cada projeto é **autocontido** (tem o próprio
`README.md`, build e deploy) e mora numa subpasta aqui.

```
funis/
└── <nome-do-projeto>/     ← copie de _modelo/projeto/
    ├── README.md          ← o que é, como rodar, URL de produção, contatos
    └── ...
```

Na Vercel, o **Root Directory** do projeto aponta para
`clientes/<cliente>/funis/<nome-do-projeto>`. Registre a URL de produção no
`README.md` do projeto.
