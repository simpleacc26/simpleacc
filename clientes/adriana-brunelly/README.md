# Adriana Brunelly

Cliente SimpleAcc desde **04/09/2026**. Decoradora de eventos e ex-dona de buffet em
Londrina/PR, **25 anos de mercado**, em transição para o digital: quer ensinar **gestão e
posicionamento** para donos de buffet, decoradores e doceiras.

**Projeto contratado:** Funil de Lead Dinâmico (quiz + páginas + tráfego + copy + design),
contrato de 6 meses. **Objetivo do funil: vender a mentoria de R$ 30 mil**, com o curso low
ticket "WhatsApp de valor" como caminho para quem não qualifica.

— e uma tese proprietária escrita, a **"Dívida de Valor"**.
