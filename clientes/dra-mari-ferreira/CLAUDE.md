# Cliente: Mariana "Dra. Mari" Ferreira (Império da Empresária da Estética)

Esta pasta é a **base de conhecimento** da cliente Dra. Mari Ferreira. Tudo que a
SimpleAcc faz para ela acumula aqui, e qualquer pessoa, de qualquer máquina,
continua de onde a outra parou (o Git é a memória compartilhada).

## Como se orientar nesta pasta

- `contexto/`   — ficha do cliente, expert, oferta, persona/ICP, linguagem, fontes.
- `estrategia/` — roteiro do onboarding, diagnóstico/lacunas e scripts comerciais.
- `copy/`       — anúncios e conteúdo (herdados do cliente, não veiculados).
- `roteiros/`   — roteiros de vídeo datados — inclui a VSL v1.
- `funis/`      — funil de quiz, páginas e trackeamento (a construir).
- `aprendizados.md` — o que funciona/não funciona (atualize sempre).

**Comece por `contexto/00-ficha-do-cliente.md`.** É a cola objetiva do projeto.

## Ao trabalhar para esta cliente

1. **Antes de criar**, leia `contexto/` e `aprendizados.md` para não recomeçar do zero.
2. Para gerar funil/página/anúncios, rode **`/prompt-mestre`** — ele já usa o contexto daqui.
3. Salve os entregáveis na pasta certa (acima) e **registre o aprendizado** em `aprendizados.md`.
4. Trabalhe numa branch `cliente/dra-mari-ferreira/<assunto>` e abra PR.
