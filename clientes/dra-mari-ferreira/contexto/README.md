# Contexto — Dra. Mari Ferreira

Base da cliente: quem é a expert, a oferta, a persona/ICP e a linguagem real do
público. É daqui que o comando `/prompt-mestre` puxa o contexto. Mantenha atualizado.

| Arquivo | O que tem |
| ------- | --------- |
| `00-ficha-do-cliente.md` | **Comece aqui.** Cola objetiva: quem é, os dois negócios, meta, contrato, riscos e lacunas. |
| `01-perfil-expert-e-oferta.md` | História, autoridade, produto, método, preço, funil pretendido. |
| `02-icp-persona.md` | Persona: perfil, estado atual, nível de consciência, medos, desejos, decisão de compra. |
| `03-linguagem-do-publico.md` | Dores, desejos, crenças limitantes e frases reais — matéria-prima de copy. |
| `fontes/` | Material original (call de vendas, canvas, dossiê), transcrito sem edição. |
