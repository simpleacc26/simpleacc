# Cliente: Pâmella Mello

Base de conhecimento da cliente **Pâmella Mello** (clínica). Tudo que a SimpleAcc
faz para ela acumula aqui — qualquer pessoa, de qualquer máquina, continua de
onde a outra parou (o Git é a memória compartilhada).

## Como se orientar nesta pasta

- `contexto/`   — quem é, oferta, ICP, números e registros de reunião (Pit Stops).
- `estrategia/` — planos de ação, diagnósticos e acompanhamento.
- `copy/`       — copy de páginas e de anúncios/criativos.
- `roteiros/`   — roteiros de vídeo (datados).
- `funis/`      — funil de quiz e páginas.
- `aprendizados.md` — o que funciona/não funciona (atualize sempre).

## Ao trabalhar para esta cliente

1. **Antes de criar**, leia `contexto/dossie-cliente.md` (quem é, oferta, Big
   Idea, funil no ar, copy existente, identidade visual) e `aprendizados.md`.
2. O documento vivo do momento é
   `estrategia/2026-08-07-pit-stop-plano-de-acao.md` — comece por ele.
3. Para gerar funil/página/anúncios, rode **`/prompt-mestre`**; para copy, **`/copy`**.
4. Salve na pasta certa e **registre o aprendizado** em `aprendizados.md`.
5. Branch `cliente/pamella-mello/<assunto>` + PR.
