# Filipe Chagas

Implementa **agentes de IA personalizados** para empresas: captura o conhecimento
do especialista que é gargalo da operação (quem sabe orçar, atender e decidir) e
transforma isso em um sistema que roda 24h, integrado ao WhatsApp. Método próprio:
**D.T.I.** — Diagnóstico, Transformação, Implantação.

A Simple Acc entrega **estruturação de oferta + roadmap de 90 dias + acesso à
metodologia** (funil e comercial) + acompanhamento por 1 ano.
**Neste projeto a Simple não implementa o funil** — o Filipe executa com o método.
