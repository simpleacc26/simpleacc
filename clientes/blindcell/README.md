# BlindCell Chapecó

Blindagem de vidro para celulares, smartwatches e tablets em Chapecó (SC) e
região. Pioneira e única na cidade. A SimpleAcc cuida de aquisição de clientes
via Meta Ads (campanha de mensagens para WhatsApp).
