## Aviso de procedência — leia antes de usar

**Os dois canvases foram preenchidos pelo Rafael com ajuda de uma IA.** Ele
mesmo diz, no material: *"vou colocar 2 observações que o agente colocou"*.

Ou seja: o texto dos canvases **não são as palavras cruas dele** — é output de
LLM que ele endossou ao enviar. Isso muda o peso das afirmações:

- **Trate como material do cliente** (ele assinou embaixo), mas
- **não trate como dado validado**. Em especial:
  - **Os preços (R$ 9.997 / R$ 14.997 / faixas R$ 8k–25k) são sugestão do
    agente de IA**, não preço que o Rafael já pratica ou já validou no mercado.
  - **"Método Cobra®" e "Método Cobra Authority®" são propostas do agente.**
    O símbolo `®` aparece no texto original mas **provavelmente não corresponde
    a registro real no INPI** — não reproduzir como marca registrada sem
    confirmar com ele.
  - As "observações do agente" estão marcadas como tal em cada arquivo.
