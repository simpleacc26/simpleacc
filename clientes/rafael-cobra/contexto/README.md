## Regra de leitura

**`fontes/` é a verdade; o resto é leitura da Simple.** Se houver divergência
entre um arquivo de síntese e a fonte bruta, a fonte ganha — e a síntese deve ser
corrigida.

⚠️ Os canvases em `fontes/` foram **preenchidos pelo cliente com ajuda de uma
IA**. Preços e nomes de método ali são **sugestão do agente**, não dado validado.
